## Overview

AADS explores autonomous cyber defense through coordinated "swarms" of AI agents that monitor, detect, and respond to threats in real time, reducing the response gap left by manual security operations.

## Contribution

- Led coordination and planning across the project's technical and non-technical workstreams
- Contributed to SIEM pipeline development for centralized security event monitoring
- Supported IDS/IPS integration for automated threat detection and response
- Owned stakeholder documentation to keep the project's direction and progress clear across the team

## Technical Approach

The system is built around containerized services using Docker and Kubernetes, with Python powering the agent logic and SIEM/IDS/IPS integrations that feed a shared detection pipeline.

## Status

AADS is an ongoing project (Nov 2025 – Present), with active work on expanding agent coordination and defense pipeline coverage.

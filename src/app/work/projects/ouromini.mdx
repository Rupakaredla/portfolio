## Overview

OuroMini is an ESP32-based wireless research platform built to explore embedded security concepts, from wireless attack surfaces to logging and monitoring, with results surfaced through a live web dashboard.

## Contribution

- Managed the project end-to-end, from initial planning through expo delivery
- Handled budgeting, timelines, and compliance requirements for the hardware build
- Produced technical documentation covering the platform's architecture and usage

## Technical Approach

Built on the ESP32 platform, OuroMini uses Wi-Fi and BLE for wireless communication, with embedded logging feeding a web dashboard for real-time visibility into platform activity.

## Status

OuroMini ran from Oct 2025 to Dec 2025 and was successfully delivered and presented at expo.

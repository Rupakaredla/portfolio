## Overview

Undershell is a women's safety application built to give users a fast, reliable way to signal for help even in poor network conditions. The project combines a React Native mobile app with an ESP32-based hardware companion to cover scenarios where a phone alone isn't enough.

## Key Features

- **SOS alerts** that instantly notify trusted contacts with the user's status
- **Live location tracking** shared in real time during an emergency
- **Signal-less SMS** fallback via a GSM module for areas with weak connectivity
- **Voice-recognition-triggered alerts**, allowing hands-free activation in high-stress situations

## Technical Approach

The app is built with React Native for cross-platform delivery, backed by Node.js and Firebase for real-time data sync, with MongoDB for persistent storage. A GSM module and a Voice Recognition API power the offline and hands-free alerting paths, while an ESP32 microcontroller integrates the hardware trigger for emergency signals.

## Status

Undershell is an active, ongoing project (Sep 2025 – Present), currently being refined alongside continued testing of the hardware integration and alert reliability.
